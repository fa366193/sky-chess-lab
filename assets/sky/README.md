# Sky reaction assets

The eight PNG files in `reactions/` are separate transparent character states:

1. watching / attentive
2. thinking / analyzing
3. encouraging / impressed
4. sassy / playful
5. teaching / explaining
6. surprised
7. announcing her move / instructive
8. celebrating / delighted

The interface crossfades between poses and applies subtle breathing and speaking
motion. Dialogue and chess coordinates remain HTML so every generated move can
be announced without creating another image.

The source visual references were the two Decision Systems Lab concept images
provided for this project. Assets were generated using the built-in image
generation tool with transparent-background prompts.
